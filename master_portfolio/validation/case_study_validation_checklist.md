# Case Study Validation Checklist

Validate each case study before marking it finalized.

- [ ] Overview is complete
- [ ] Problem statement is complete
- [ ] Solution description is complete
- [ ] Technology stack is listed
- [ ] Outcomes are listed
- [ ] Screenshots or links are included
- [ ] Canonical repository is identified
- [ ] Archived duplicate repos are listed (or explicitly marked as none)
- [ ] Naming follows the standard in `master_portfolio/case_studies/`
