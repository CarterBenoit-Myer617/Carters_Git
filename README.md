# Carters_Git

This repository is now the **master portfolio workspace** used to consolidate, validate, and finalize portfolio case-study code.

## Master Structure

- `master_portfolio/case_studies/` - active canonical case studies
- `master_portfolio/shared_assets/` - shared images, media, and reusable assets
- `master_portfolio/archived_repos/` - archive-only references for non-canonical duplicates
- `master_portfolio/inventory/` - repository inventory and duplicate analysis
- `master_portfolio/validation/` - case-study validation checklist

## Workflow

1. Add all portfolio repositories to `master_portfolio/inventory/repository_inventory.csv`.
2. Record duplicate groups and canonical choices in `master_portfolio/inventory/duplicate_analysis.md`.
3. Create/update case studies using `master_portfolio/case_studies/_TEMPLATE_CASE_STUDY.md`.
4. Validate each case study with `master_portfolio/validation/case_study_validation_checklist.md`.
5. Track migration/finalization in `master_portfolio/portfolio_migration_tracker.md`.
6. Complete `master_portfolio/final_review.md` before portfolio publication.
